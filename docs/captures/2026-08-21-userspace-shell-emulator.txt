Blackroo Linux — userspace shell (brsh) as pid 1
================================================
Captured 2026-08-21, PCSX-Redux (SIO1 raw TCP server on :6699),
output/blackroo.exe build #52, loaded with -loadexe -run.

This is the milestone capture docs/25-ROOT-MOUNT-JOURNEY.md describes; no
capture had been filed for it, so the transcript in that document was the only
record. Reproduced here from scratch in a fresh session.

Reproduce:
  1. ~/.config/pcsx-redux/pcsx.json -> emulator.Debug.{SIO1Server:true,
     SIO1ServerPort:6699, SIO1Mode:1}      <-- NOTE: emulator.Debug, NOT emulator
  2. PCSX-Redux-HEAD-x86_64.AppImage -loadexe output/blackroo.exe -run
  3. connect to 127.0.0.1:6699, send "cont" to leave BRMON

--- notes ---
Card probing takes ~2.5 minutes in emulation (8 slots, each timing out); the
kernel is not hung, it is waiting on absent hardware. On the console this is
fast.

Not yet reproduced on real hardware: output/blackroo.bin (the burned ISO) is
from 08:03, older than the 17:25 kernel that contains binfmt_fixed/brcon/brsh,
so the CD-R in existence does NOT carry this kernel. Hardware proof needs
either a fresh burn or a serial upload of output/blackroo.exe to kloader.
