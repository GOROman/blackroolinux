Blackroo Linux - the tty layer works: userspace output on the GPU
=================================================================
Captured 2026-08-21 on a PAL SCPH-750x. Build #54.

The line that settles it:

    BLACKROO: /dev/console -> console "tty0" = tty device 4:1

4:1 is tty1 - the VT, drawn on the TV by psxvga_con. Before the fix this same
line would have read 4:64, which is ttyS0, the serial tty: that is where every
userspace write to /dev/console used to go, and where it hung.

brsh then opens it as fd 4 (separate from /dev/brcon on fd 3, which it still
uses for INPUT - there is no keyboard driver yet) and the write returns instead
of sleeping in the line discipline.

Everything below appeared BOTH on the television and on this serial link: the
GPU via do_con_write -> psxvga_putcs, the serial via blackroo_con_mirror().
Chelson confirmed the banner, prompt and typed text on the TV.
